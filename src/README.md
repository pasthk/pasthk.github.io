## 以文獻重新理解香港
　　香港是一座具有豐富文字記錄的城市。報紙、政府公報、廣告、聲明、訃告、調查報告及後來的研究論著，共同構成理解香港歷史的重要材料。然而，這些資料往往分散於不同報刊、檔案、圖書館與出版物之中；即使同一事件，也可能以不同時間、不同媒介與不同語言呈現。

　　「香港文獻類編」旨在將此類材料加以整理與索引，建立一個以歷史事件為中心的檢索框架，並以此作為研究與閱讀的入口。現階段，工作重點在於整理香港舊新聞及相關文獻，並逐步按主題與事件擴充內容。

## 以事類編
　　本資料集採取**「以事類編」**的整理方式，以歷史事件作為基本單位，將同一事件所牽涉的不同文獻集中編排，而不僅依賴報刊、年份或作者作分散列舉。

　　一個事件可能同時涉及新聞報道、官方文件、學者論述、調查報告、保存工程及後續研究。因此，本索引的功能不在於替代原始文獻的解釋，而在於建立材料之間的關聯，使讀者能從不同時期、不同來源與不同表述中追索事件的發展與延展。

　　以李鄭屋漢墓為例，相關資料包括1955年前後的新聞報道、政府新聞公報、調查與發掘報告，以及後來的研究論著。透過集中編排，可以較完整地呈現一項考古發現由發現、發掘、討論到保存與研究的文獻脈絡。

## 資料來源與內容
　　資料主要來自香港公共圖書館多媒體資訊系統中的「香港舊報紙」，並逐步補充其他歷史報刊與研究資料。現有整理涵蓋多種中英文報刊，包括《遐邇貫珍》《循環日報》《香港華字日報》《工商日報》《工商晚報》《大公報》《華僑日報》、*Hong Kong Daily Press*、*China Mail*、*South China Morning Post*等。

　　除新聞報道外，資料亦包括商業廣告、政府佈告、聲明、調查與發掘報告，以及後來的學術研究。這些材料雖然形式各異，卻共同能從不同角度反映香港的社會、文化、制度與城市發展。

## 編纂原則與資料使用
　　在整理報刊資料時，盡量保留篇名、日期、報刊名稱、版次或頁碼等原始資訊；如遇缺期、缺頁或其他資料不完整之處，則予以說明，而不以推測填補。

　　此類編的定位是文獻索引與研究線索，而非原始資料的替代品。當原始文獻可供查考時，仍應以原報刊、檔案、正式出版物及相關資料庫為依據。

## 從索引走向研究
　　歷史不只存在於宏大的政治事件中。一處古蹟、一份政府公告、一則廣告、一場公共爭論，甚至一篇訃告，都可能成為理解香港社會的切入點。

　　我們希望藉此將分散的文字記錄重新連結起來，為一般讀者提供探索香港歷史的入口，同時為研究者提供尋找原始資料、追索事件脈絡及建立研究問題的索引。
