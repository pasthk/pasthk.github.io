## 以文獻重新理解香港
　　香港是一座留下大量文字記錄的城市。報紙、政府公報、廣告、聲明、訃告、調查報告及後來的研究論著，共同構成理解香港歷史的重要文獻。然而，這些材料往往分散於不同報刊、資料庫、圖書館及出版物之中；即使同一事件，也可能見於不同日期、不同報紙及不同類型的文獻。

　　「香港文獻類編」是一個以香港歷史文獻整理與索引為核心的個人研究項目，現階段主要整理香港舊新聞及相關文獻，並持續按主題與事件擴充資料。

## 以事類編
　　本資料集採取**「以事類編」**的方式，以歷史事件作為整理單位，將同一事件涉及的不同文獻集中編排，而不只按照報刊、年份或作者分散列舉。

　　一個事件可能同時涉及新聞報道、政府文件、學者意見、調查報告、保存工程及後來的研究。因此，索引的目的不是替文獻作出預設性的歷史解釋，而是建立不同材料之間的關聯，使讀者可以從不同時期、不同來源的記錄中追索事件的發展與後續研究。

　　例如李鄭屋漢墓，相關資料便包括1955年前後的新聞報道、政府新聞公報、調查與發掘報告，以及後來的研究論著。透過集中編排，可以較完整地呈現一項考古發現由發現、發掘、討論到保存及研究的文獻脈絡。

## 資料來源與內容
　　資料主要來自香港公共圖書館多媒體資訊系統中的「香港舊報紙」，並逐步補充其他歷史報刊及研究資料。現有整理涉及多種中英文報刊，包括《遐邇貫珍》《循環日報》《華字日報》《工商日報》《工商晚報》《大公報》《華僑日報》、*Hong Kong Daily Press*、*China Mail*、*South China Morning Post*等。

　　除新聞報道外，資料亦包括商業廣告、政府佈告、聲明、調查與發掘報告，以及後來的學術研究。這些看似零散的資料，往往能從不同角度反映香港的社會、文化、制度與城市發展。

## 編纂原則與資料使用
　　在整理報刊資料時，盡量保留篇名、日期、報刊名稱、版次或頁碼等原始信息；如遇缺期、缺頁或其他資料不完整的情況，則盡可能加以說明，而不以推測填補。

　　目前的整理以1946年為重要分界，分階段推進，現階段主要集中於1946年以後的資料，並逐步擴充其他時期及文獻類型。

　　此類編的定位是文獻索引與研究線索，並非原始資料的替代品。當原始文獻可以查考時，仍應以原報刊、檔案、正式出版物及相關資料庫為依據。由於資料數量龐大，類編仍在持續整理之中，亦難免存在遺漏或編纂上的錯誤。

## 從索引走向研究
　　歷史並不只存在於宏大的事件之中。一處古蹟、一份政府公告、一則廣告、一場公共爭論，甚至一篇訃告，都可能成為理解香港社會的一個切口。

　　我們希望將這些分散的文字記錄重新連接起來，為一般讀者提供探索香港歷史的入口，也為研究者尋找原始資料、追索事件脈絡及建立研究問題提供索引。
