　　安陽位於河南省北部，地處洹河流域，是中國古代都邑與考古研究的重要區域。從商代城址、宮殿宗廟和王陵，到東漢末年的陵墓遺址，以及後世的佛教建築、歷史人物紀念地與近代陵園，安陽的文化遺存反映不同時期的政治、信仰、城市建設與社會記憶。本專題以遺址為線索，介紹安陽的重要文化史跡，並整理相關發掘報告、考古簡報、圖錄及研究論著，方便讀者追查材料來源與學術討論。

## 殷墟與甲骨文
　　殷墟位於安陽小屯一帶，是晚商都邑遺址。自1928年開始的考古發掘，陸續揭示宮殿宗廟區、王陵區、手工業作坊及多種墓葬，出土甲骨、青銅器、玉器等重要遺物。甲骨卜辭保存商代文字與占卜記錄，是研究商代政治、祭祀、社會及歷史年代的重要材料。殷墟於2006年列入《世界遺產名錄》。本站的[殷墟考古報告索引](./yinxu/report.md)、[研究論著](./yinxu/article.md)與[器物圖錄](./yinxu/catalogue.md)，按類別整理相關出版資料。

## 洹北商城
　　洹北商城位於洹河以北，是安陽另一處重要的商代城址。考古工作發現城垣、宮殿區夯土建築及鑄銅作坊等遺存，為認識商代城市布局、宮殿建築和手工業生產提供了材料。洹北商城的年代、性質及其與殷墟的關係仍是學界研究議題；本站整理了[洹北商城發掘報告](./huanbei-shang-city/report.md)與[相關研究論著](./huanbei-shang-city/article.md)，供讀者按來源進一步查考。

## 曹操高陵
　　曹操高陵位於安陽市安陽縣安豐鄉西高穴村一帶。西高穴墓葬於2008年發掘，考古機構其後公布將其認定為曹操高陵；墓葬形制、出土器物及石刻文字等，構成相關研究與辨析的重要材料。遺址的辨認及歷史解讀亦曾引發討論，因此本頁所列資料兼收發掘報告與不同觀點的研究論著，讀者可參閱[考古報告](./cao-cao-mausoleum/report.md)及[相關論著](./cao-cao-mausoleum/article.md)，並留意各文獻的證據與論證。
